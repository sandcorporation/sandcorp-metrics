# 0002. 방문자는 쿠키 없이 하루 해시로 센다

- 상태: 채택 (2026-10-23, #1)

## 맥락

「오늘 방문자」·「누적 방문자」를 세려면 같은 사람의 조회를 묶어야 한다. 쿠키나 localStorage 식별자를 쓰면 동의 배너가 필요하고 사람을 날짜를 넘어 따라가게 된다. IP·User-Agent 원본을 저장하면 개인정보를 쌓게 된다. 공개하는 숫자는 규모만 보여 주면 되고 개인 단위 분석은 필요 없다.

## 결정

- `visitor = sha256(그날의 소금 ‖ 사이트 키 ‖ IP ‖ User-Agent)`의 앞 32자를 조회에 남긴다. IP·User-Agent 원본은 저장하지 않고 로그에도 남기지 않는다.
- 소금은 날마다(Asia/Seoul) 새로 만드는 32바이트 무작위 값이며 이틀 지나면 지운다. 소금이 사라지면 지난 해시를 같은 사람과 다시 이을 수 없다.
- 「오늘 방문자」는 그날 고유 해시 수(정확), 「누적 방문자」는 일별 고유 수의 합이다. 날을 넘어 같은 사람은 여러 번 세진다.
- 사이트 키를 해시에 넣어 같은 사람이라도 사이트끼리 묶이지 않는다.
- 쿠키·동의 배너는 두지 않는다.

## 결과

- 누적 방문자는 「고유 사람 수」가 아니라 「방문한 사람-날 수」다. 화면 문구도 그렇게 읽히게 한다.
- 같은 공인 IP·같은 브라우저를 쓰는 여러 사람(회사·학교 NAT)은 하루 안에서 한 명으로 세진다.
- 조회 원본은 90일 뒤 지우고, 그 뒤에는 일별 집계만 남는다.
